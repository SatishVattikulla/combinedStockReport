An automated financial intelligence and consensus engine auditing **3,612 dated stock recommendations** across **1,119 unique listed equities** (2021–2026) from four prominent Indian market analysts:
1. **Sai Krishna Patri** (*Money Purse / Sunday Show*)
2. **Akshay Srivastava**
3. **Pranjal Kamra** (*Finology*)
4. **CA Rachana Ranade**

---

## 🎯 What This System Answers

Instead of simply putting analysts side-by-side, this platform answers the critical questions an investor actually cares about:
- **Which stocks do multiple analysts independently favour?** (Unanimous 4/4 and strong 3+ consensus).
- **Whose historical calls have performed best?** Separating genuine stock-picking skill (Alpha vs Nifty 50) from general bull-market rising tides.
- **Which analysts excel at valuation, forensic accounting, or identifying multibaggers?**
- **Where do analysts clash, and what explains the disagreement?** (Examining valuation multiples vs TAM vs balance sheet debt).
- **Which commonly recommended stocks still look attractive at today's valuation?**

## 💻 Repository Structure & Key Files

```text
├── index.html                   # Primary interactive dashboard (enabled for GitHub Pages)
├── report.html                  # Standalone mirror copy of web dashboard
├── build_master_engine.py       # Python pipeline compiling datasets, leaderboards & consensus
├── start_server.bat             # 1-click Windows batch launcher for local Wi-Fi hosting
├── serve_network.py             # Python HTTP server with automatic LAN IP discovery
├── combined_master_dataset.json # All 3,612 normalized recommendations with benchmark alphas
├── consensus_stocks_master.json # 1,119 equities with multi-analyst consensus ratings
├── analyst_leaderboard.json     # Quantitative metrics, sub-scores, and ranks
├── disagreement_matrix.json     # 42 battleground stocks with opposing bull/bear quotes
└── EQUITY_L.csv                 # Official NSE equity master list
```

## 🚀 How to Run Locally

### 1. Host on your Local Wi-Fi (Phone, Tablet, Laptop)
Simply double-click `start_server.bat` or run:
```bash
python serve_network.py
```
Open the provided link in your browser:
- On this PC: `http://localhost:8080`
- On your phone (same Wi-Fi): `http://<your-lan-ip>:8080`

### 2. Regenerate / Re-run the Full Audit
```bash
python build_master_engine.py
```
